# Limitations, safety and honest status

- **No clinical validation:** every patient profile, physiological stream and outcome label is synthetic. The generator is not a calibrated lung/clinical disease model. No real participant, device feed, hospital partner or clinical trial is claimed.
- **Poor forecasting evidence:** primary72h AUROC0.3951, AUPRC0.0593 below prevalence0.0773; LR is better at72h. No consistent ablation improvement. Zero sensitivity for all primary horizons at.35; zero of5 held-out test-window onsets detected. Do not claim useful clinical warning, treatment benefit or hospitalization reduction.
- **Unstable calibration:** the72h Platt slope is negative, reversing raw tree-score direction. Raw TreeSHAP signs do not indicate calibrated risk direction. Independent horizon estimates may be non-monotonic.
- **Small/dependent evaluation:** only24 test patients,5 event onsets and correlated hourly labels. Shared city ambient values create cross-subject dependence. Patient-cluster bootstrap does not resolve all uncertainty or establish clinical generalizability.
- **Exposure limitations:** gridded historical ambient/weather products are not indoor, occupational, individual dose or verified as-issued production forecasts; archives may be revised. Cache dates are visibly historical, not current conditions.
- **Scenario limitations:** conditional feature paths hold physiology fixed. No causal or validated mechanistic response is modeled. Lower modeled exposure may counterintuitively increase predicted score. No scenario is medical advice.
- **Not a production medical system:** local demo auth is off by default. Optional shared write token is not RBAC; read-only endpoints/WebSocket remain public. No regulated retention, real-device/EHR ingestion, production consent, encryption-at-rest assurance or multi-worker coordination. Use one backend worker; never enter real patient data or load untrusted model bundles.
- **Reset destroys demo records:** alerts, actions, scenarios and versions are cleared and deterministically recreated. This is not an acceptable real medical-record retention workflow.
- **Retrospective false-positive demo:** PG-0071/hour1051 is score-selected across the full synthetic cohort, with72h label0. It is not a prospective held-out detection success.
- **External submission incomplete:** actual team/institution details, public GitHub repository, actual Unlisted YouTube video and signed-out public artifact/playback checks remain pending. A local preview, generated file, storyboard or script does not satisfy those items.
- **Source gap disclosed:** the referenced idea DOCX was absent; the user explicitly authorized the supplied master message as the specification. No unavailable document content was invented.

Next steps require new pre-registered development data, ethics/consent and adjudicated real outcomes, prospective patient/time/site validation, calibrated uncertainty/fairness studies, secure ingestion and clinician governance. A defensible causal or mechanistic model is required before discussing intervention effects. This prototype is not for diagnosis, triage, prescribing, treatment or emergency decisions.
