# Mandatory recording/upload checklist — owner action

All unchecked items below require actual evidence, not a generated script.

- [ ] Team and institution confirmed and shown accurately.
- [ ] Full live demo rehearsed using the timed script and deterministic scenario.
- [ ] Actual final video recorded with legible UI and audible narration.
- [ ] Actual duration meets the current official requirement (target20minutes; user requirement15–20).
- [ ] Includes problem, architecture, provenance, twin, live replay, horizon predictions, explanations, alerts/actions, scenario, evaluation, technical walkthrough and limitations.
- [ ] Every patient is visibly identified as synthetic; no real personal data or secrets appear.
- [ ] False-positive demo and poor72h results are not narrated as clinical success.
- [ ] No causal treatment effect, guaranteed prevention or clinical benefit is claimed.
- [ ] Actual file reviewed locally for blank frames, clipped text, dropped audio and incorrect numbers.
- [ ] Uploaded to the correct YouTube account with visibility **Unlisted**, not Private.
- [ ] Video processed and playback verified in a signed-out/incognito browser.
- [ ] Actual URL, duration and verification date entered in `submission_metadata.json`.
- [ ] Actual URL inserted into root README and VIDEO_STATUS.md, replacing pending text.
- [ ] Final README/deck/diagram/report committed to the actual public GitHub repository.
- [ ] Public README, PPTX/PDF files, screenshots and architecture open without permissions.
- [ ] Public link audit rerun and human YouTube playback check documented.
- [ ] Challenge form submitted only after the final gate is re-evaluated.
